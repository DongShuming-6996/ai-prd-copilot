# 运营评估报告 · Q2 质检指标与看板使用分析

## 一、结论摘要

Q2 质检整体运行平稳，但数据口径混乱问题突出，人工汇总成本高，看板建设必要性充分。

## 二、关键数据（Excel 手工汇总口径）

| 指标 | Q2 数值 | 环比 |
| --- | --- | --- |
| 质检总量 | 42,860 | +8.3% |
| 抽检率（人工复核比例） | 5.1% | 持平 |
| 质检合格率 | 82.3% | -1.8pct |
| 异常率 | 3.2% | +1.1pct |
| 平均质检时效 | 4.5 小时 | +0.6h |

## 三、口径说明

本报告合格率按坐席应答条数口径计算（合格坐席应答条数 / 坐席应答总条数），与数据字典评审会确定的 case 维度通过率口径不同，两者数值存在差异，属于历史遗留口径，看板上线后需统一。

## 四、发现的问题

1. 异常率连续两月上升，主要集中在新坐席与 AppChat 渠道；
2. 抽检率长期低于目标 10%，人工复核覆盖率不足；
3. 质检时效在月末集中积压，均值被拉高；
4. 不同人导出汇总结果不一致，月度例会前需反复核对。

## 五、建议

看板优先支持趋势监控与异常下钻，其次补充坐席维度分析；建议看板上线后以统一口径重新出具 Q3 报告。
