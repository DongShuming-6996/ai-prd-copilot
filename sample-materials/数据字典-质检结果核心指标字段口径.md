# 数据字典 · 质检结果核心指标字段口径（V0.9）

## 一、基础字段

| 字段 | 说明 | 来源 |
| --- | --- | --- |
| case_id | 售后 case 唯一标识 | 售后系统 |
| channel | 渠道：phone / appchat / email | 售后系统 |
| agent_id | 坐席 ID | 坐席系统 |
| qc_user_id | 质检员 ID | 质检库 |
| auto_result | 自动质检结果：pass / fail / review | qc_result |
| manual_result | 人工质检结果：pass / fail | qc_result |
| qc_status | 质检状态：pending / done / appeal | qc_result |
| qc_time | 人工质检完成时间 | qc_result |
| complaint_flag | 投诉标记：0/1 | 质检详情 |

## 二、指标口径

| 指标 | 定义 |
| --- | --- |
| 质检总量 | 统计周期内完成质检的 case 数 |
| 抽检率 | 人工复核 case 数 / 质检总量，目标 10% |
| 通过率 | 人工质检结果为通过的 case 数 / 质检总量（case 维度） |
| 异常率 | 自动或人工任一判为异常的 case 数 / 质检总量 |
| 平均质检时效 | 平均（人工质检完成时间 - 进入人工质检时间），单位小时 |

## 三、同步策略

质检库 qc_result 表每日 02:00 增量同步至 BI 数仓，看板统一读 BI，数据 T+1；测试数据与已删除 case 需过滤。
