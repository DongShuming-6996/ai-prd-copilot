# 竞品参考 · 同行业客服质检看板功能对标

## 一、对标对象

选取三家主流客服质检平台（A 平台、B 平台、C 平台）的质检看板能力进行对标。

## 二、功能对标结果

| 能力 | A 平台 | B 平台 | C 平台 | 本产品现状 |
| --- | --- | --- | --- | --- |
| 指标总览卡 | 有 | 有 | 有 | 无 |
| 趋势分析 | 有 | 有 | 有 | 无 |
| 异常下钻 | 有 | 部分 | 有 | 无 |
| 坐席排行 | 有 | 有 | 无 | 无 |
| 报告导出 | 有（PDF） | 有（Excel） | 无 | 无 |
| 预警推送 | 有 | 无 | 有 | 无 |
| 优秀案例联动 | 无 | 无 | 无 | 无（平台已有优秀案例功能，可联动） |

## 三、差异化建议

1. 本平台已具备「优秀案例」与「复盘」功能，看板可联动优秀案例标记，形成质检运营闭环，这是竞品不具备的差异化能力；
2. 预警能力建议至少做到阈值展示，推送可二期；
3. 权限模型参考行业标准：管理员全局、组长本组、坐席本人，避免直接暴露个人排名引发纠纷。

## 四、结论

看板核心能力（总览、趋势、下钻、排行、导出）为行业标配，本产品应补齐；差异化在于与既有复盘/优秀案例能力的联动。
