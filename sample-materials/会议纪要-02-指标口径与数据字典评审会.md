# 会议纪要 02 · 指标口径与数据字典评审会

- 时间：2026-04-08 10:00-11:30
- 参会：产品（林）、运营（陈）、质检主管（周）、BI（吴）、后端（赵）

## 一、评审结论

1. 通过率口径：本期统一按 case 维度计算，定义为「质检结果为通过的 case 数 / 质检总量」；坐席维度合格率（按坐席应答条数）需求真实存在，但口径复杂，列为二期。
2. 异常率口径：异常 case 数 / 质检总量，异常包含自动质检与人工质检任一判为异常。
3. 抽检率口径：人工复核 case 数 / 质检总量，目标 10%。
4. 平均质检时效口径：人工质检完成时间与进入人工质检时间之差的平均值，单位小时。
5. 数据来源：质检库 qc_result 表每日 T+1 同步至 BI 数仓，看板统一读 BI 数据；同步任务由 BI 侧维护，质检侧提供业务校验。
6. 投诉标记字段在质检详情中存在，但列表与导出中缺失，需在本次看板项目中补齐字段与口径。

## 二、争议点记录

- 运营提出坐席维度「合格率」为最常用指标，希望本期就上；会议结论为本期先按 case 口径，坐席维度合格率在二期随坐席排行一同上线，避免一期口径混乱。
- 时间粒度：产品建议默认近 7 天可切换，运营希望默认近 30 天，待交互评审会再定。
