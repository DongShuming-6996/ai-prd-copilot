# AI PRD Copilot 部署手册（作品集上线）

目标：把本地应用发布上线，访客打开链接即可使用；API Key 只存在服务端，前端零配置。

架构：

- 前端：纯静态 SPA（`index.html` + `css/` + `js/`）→ 部署到 Vercel
- AI 代理：Vercel Serverless Function（`api/ai.js`），Key 在 Vercel 环境变量
- 数据：当前版本用浏览器 localStorage；Supabase 持久化为阶段 2（可选）
- 域名：腾讯云域名 CNAME 到 Vercel
- 代码：GitHub 仓库，可选 GitHub Actions 自动部署

---

## 第 1 步：GitHub 仓库

1. 打开 https://github.com/new 创建仓库（建议 `ai-prd-copilot`，公开或私有皆可，作品集建议公开）。
2. 在仓库页复制远程地址（HTTPS 或 SSH）。
3. 本地推送（在 `ai-prd-copilot` 目录执行）：

```bash
git init
git add .
git commit -m "feat: AI PRD Copilot 初版"
git branch -M main
git remote add origin <你的仓库地址>
git push -u origin main
```

> 注意：`.gitignore` 已排除 `.env*`，推送前确认没有把任何密钥提交进仓库。

## 第 2 步：Vercel 部署（推荐 Git 集成，零配置自动部署）

方式 A（最简单，推荐）：Vercel 网页端导入

1. 打开 https://vercel.com/new → Import Git Repository → 选刚推送的 GitHub 仓库；
2. Framework Preset 选 Other；Root Directory 默认（仓库根目录）；
3. 点 Deploy，等构建完成；
4. 进入项目 → Settings → Environment Variables，添加：
   - `OPENAI_API_KEY` = 你的 Key（Production + Preview + Development 都加上）
   - （可选）`ALLOWED_ORIGINS` = `https://你的域名`（来源校验，防止被别处调用）
5. 重新 Deploy（或改代码 push 触发），完成后打开部署域名验证。

方式 B：CLI 部署

```bash
vercel login
vercel link          # 关联/创建项目
vercel env add OPENAI_API_KEY production   # 粘贴 Key
vercel --prod
```

验证：

- 打开 `https://<项目名>.vercel.app`，顶栏徽标应显示「真实模型模式 · 服务端 Key」；
- 生成一份 PRD 确认真实模型链路可用；
- 若显示 Demo 模式，说明环境变量没生效（重新 Deploy 或检查 Settings → Environment Variables）。

## 第 3 步：腾讯云域名绑定

1. 在 Vercel 项目 Settings → Domains 添加你的域名（如 `prd.example.com`）；
2. 到腾讯云 DNS 控制台给域名加一条 CNAME 记录，指向 Vercel 提示的目标（如 `cname.vercel-dns.com`）；
3. 等 DNS 生效（几分钟到几小时），Vercel 会自动签发 HTTPS 证书；
4. 绑定后把 `ALLOWED_ORIGINS` 设为你的域名并重新部署。

## 第 4 步（可选 · 阶段 2）：Supabase 数据持久化

当前版本数据存浏览器 localStorage，作品集演示够用。若要多人共享数据：

1. 打开 https://supabase.com → New Project；
2. SQL Editor 中执行 `supabase/schema.sql`（建 `projects` / `user_settings` 表，已启用 RLS）；
3. 前端接入 supabase-js（Auth + 读写 `projects` 表），把 localStorage 读写替换为数据库调用；
4. 若想用 Supabase Edge Function 替代 Vercel Function 做 AI 代理，可复用 `lib/ai-proxy.js` 的逻辑迁移到 `functions/`，Key 放 Secrets。

## 第 5 步：上线检查清单

- [ ] 顶栏徽标显示「真实模型模式 · 服务端 Key」
- [ ] 匿名访客无需任何配置即可生成 PRD
- [ ] `ALLOWED_ORIGINS` 已设置（防盗用）
- [ ] Key 未出现在 GitHub 提交历史 / 前端代码中
- [ ] 设置页「服务端 Key」状态为「已配置」
- [ ] 建议观察用量：Vercel 项目 Usage 页查看 Function 调用量，异常时临时删除环境变量即可回退 Demo 模式

## 常见问题

- **部署后仍 Demo 模式**：环境变量没配或没生效 → Settings → Environment Variables 检查，重新 Deploy。
- **API 返回 500**：看 Vercel 项目 Logs（`vercel logs`），通常是 Key 无效或模型名不对。
- **刷新页面 404**：检查 `vercel.json` 的 rewrite 是否生效（`/((?!api/).*)` → `/index.html`）。
- **CI 部署失败（GitHub Actions）**：需要 Vercel Account → Settings → Tokens 创建 `VERCEL_TOKEN`，加到仓库 Secrets；本地 `vercel link` 后把 `.vercel/project.json` 提交到仓库。
